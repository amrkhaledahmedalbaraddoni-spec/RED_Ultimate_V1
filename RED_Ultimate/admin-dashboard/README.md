# `admin-dashboard/` — لوحة التحكم (نموذج قديم ثابت)

نسخة مبكرة/تجريبية من لوحة التحكم — ملفان فقط، **بيانات ثابتة Mock، بدون أي اتصال بالخادم**. استُبدلت بالنسخة الكاملة في `admin_dashboard/`.

> **يُنصح بحذف هذا المجلد أو تجاهله** — اللوحة النشطة هي `admin_dashboard/`.

---

## 📁 المحتوى

```
admin-dashboard/src/pages/
├── Dashboard.tsx      ← إحصائيات ثابتة (1254 مستخدم، 85420 رسالة...) + رسم ECharts ثابت
└── UserApproval.tsx   ← جدول موافقات بـ useState محلي فقط (John Doe / Alice Smith)
```

| الملف | الوظيفة | حالة الاتصال |
|---|---|---|
| `Dashboard.tsx` | لوحة إحصائيات + "Dumin Gateway Status" + زر Restart (غير عامل) | ❌ لا fetch |
| `UserApproval.tsx` | جدول موافقات يعدّل الحالة محليًا فقط | ❌ لا fetch/POST |
